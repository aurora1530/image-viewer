# ローカル画像ビューワー

ローカルのフォルダーから画像・動画を高速で閲覧できるデスクトップ／Webアプリケーションです。

## デスクトップ版

Electron 版では、選択したフォルダーを端末内のライブラリへ保存します。次回からホーム画面の「最近使ったフォルダー」をクリックするだけで開けます。よく使うフォルダーは ★ でお気に入りに固定できます。

- フォルダー履歴とお気に入りフォルダーは Electron のユーザーデータ領域に保存
- フォルダー一覧は更新時刻をキーに最大500件まで永続キャッシュ
- 画像・動画はローカルストリームから直接読み込み、巨大ファイルのコピーを回避
- 既存の `.image-viewer.json` による画像のお気に入り、非表示、表示設定を継続利用
- 外部 CDN に依存せずオフラインで起動

### 開発起動

```powershell
npm install
npm run desktop:dev
```

### Windows アプリの生成

```powershell
# 展開版
npm run desktop:pack

# インストーラーとポータブル版
npm run desktop:build
```

生成物は `release` フォルダーに出力されます。Windows では一時フォルダーでパッケージ化してから `release` にコピーするため、ビルド時の出力フォルダーのリネーム失敗を避けられます。

## 機能

- **フォルダ選択**: File System Access APIを使用してローカルフォルダを直接選択
- **画像表示**: JPG、PNG、GIF、WebP、BMPなどの画像形式をサポート
- **動画再生**: MP4、WebM、MOV、OGGなどの動画形式をサポート
- **見開き表示**: 単一表示と見開き表示の切り替え
- **サムネイル表示**: 4段階のサムネイルサイズ調整
- **サムネイル設定保存**: 選択したサムネイルサイズを次回起動時も保持
- **縮小サムネイルのキャッシュ**: 長辺1280px以下の画像を生成し、メモリに最大1000件保持。デスクトップ版は端末内にも約2000件まで保存し、次回起動時に再利用。更新ボタンで元画像の変更を反映（GIF・WebP・アニメーションPNGは原画像の動きを維持）
- **大量一覧の仮想表示**: 200件を超える一覧は画面周辺のカードだけを生成。通常一覧・全画像一覧・お気に入り一覧で、元サイズ表示やフォルダーへ戻った際の位置復元に対応
- **サムネイルの並列生成**: CPU数に応じて最大8本のWorkerでデコード・縮小・圧縮を実行。保存は表示後に非同期で行い、画面操作への負荷を軽減
- **ソート機能**: ファイル名の昇順・降順ソート
- **キャッシュ機能**: 一度読み込んだフォルダの内容を保持し、ソート変更時の再読み込みを高速化
- **再帰一覧**: サブディレクトリを含めて全画像を表示
- **再帰一覧のキャッシュ**: 収集結果をメモリに保持し、検索・並べ替え・絞り込みで再走査を省略。外部で画像を追加・削除した場合は更新ボタンで再取得
- **検索フィルタ**: ディレクトリ名・ファイル名での部分一致検索
- **キーボード操作**: 矢印キーでのページ送り、Escキーでの終了
- **ページ先読み**: 表示中の画像と前後各2枚を読み込み・デコードして保持（最大6枚）。ページ送りで再利用し、ビューワーを閉じると解放
- **全画面表示**: フルスクリーン表示に対応
- **フォルダ階層**: 上の階層への移動とパスのコピー

## 使用方法

1. デスクトップ版を起動するか、`npm run dev` でWeb版を起動します
2. 「ルートフォルダを選択」ボタンをクリックしてフォルダを選択
3. 画像やフォルダのサムネイルをクリックして閲覧を開始
4. 必要に応じて「全画像一覧」ボタンを押すと、サブディレクトリも含めた画像を確認ダイアログ後にまとめて表示できます

## テスト

初回は `npm install` と `npx playwright install chromium` を実行します。

```powershell
npm test                 # 単体・統合テスト
npm run test:typecheck   # テストコードの型チェック
npm run test:e2e         # Chromium での操作テスト
npm run test:desktop     # Electron での操作テスト
npm run test:coverage    # 単体・統合テストのカバレッジ
```

操作テストは自動で Vite を起動し、一時フォルダー内のテスト用ファイルを使います。テストの対象と移行時の確認項目は [TEST_PLAN.md](TEST_PLAN.md) を参照してください。カバレッジ表示には Chromium・Electron の操作テストは含まれません。

## 対応ブラウザ

- Google Chrome（推奨）
- Microsoft Edge
- その他のChromium系ブラウザ

※ File System Access APIが必要なため、Firefox、Safariなどは非対応です。

## 技術仕様

- HTML5 + CSS3 + JavaScript（ES6+）
- ローカルCSS（外部CDN不要）
- File System Access API
- スタイルシート(`style.css`)とスクリプト(`script.js`)を分割

- レスポンシブデザイン対応

# ローカル画像ビューワー

端末内のフォルダーから画像・動画を閲覧するアプリケーションです。サムネイル一覧から画像を開き、見開き表示でページを送れます。Windows のデスクトップ版と Web 版があります。

## 起動方法

### デスクトップ版

Windows 版の実行ファイルを起動します。ホーム画面には最近使ったフォルダーが表示され、次回から選び直さずに開けます。よく使うフォルダーは ★ でお気に入りに登録できます。オフラインでも利用できます。

### ソースから起動する場合

Node.js と npm が必要です。リポジトリのフォルダーで依存関係をインストールします。

```powershell
npm ci
```

デスクトップ版を起動する場合:

```powershell
npm run desktop:dev
```

Web 版を起動する場合:

```powershell
npm run dev
```

Web 版は表示された URL をブラウザーで開きます。フォルダー選択に対応した Chrome・Edge などの Chromium 系ブラウザーを使用してください。

## 基本の使い方

1. 「ルートフォルダを選択」、またはホーム画面の「新しいフォルダーを開く」で、閲覧するフォルダーを選びます。
2. 一覧の画像をクリックすると画像ビューワーが開き、動画をクリックすると再生が始まります。
3. フォルダーのサムネイルや名前をクリックすると、そのフォルダーの一覧へ移動します。カードの「開く」ボタンでは、フォルダー内の画像を直接閲覧できます。
4. 「上の階層へ」で親フォルダーに戻ります。デスクトップ版では「ホーム」から最近使ったフォルダーを選び直せます。

## 一覧を探しやすくする

画面下部のツールバーで表示を調整できます。

| 操作             | 内容                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------- |
| サムネイルサイズ | 「小・中・大」と、画像の縦横比を保つ「元サイズ 小・中・大」の6種類から選択               |
| 種別             | すべて・ディレクトリ・画像・GIF・動画で絞り込み                                          |
| 検索             | フォルダー名・ファイル名の一部で検索。大文字・小文字は区別しない                         |
| 名前の昇順・降順 | 数字を含む名前を考慮して並べ替え                                                         |
| UI非表示         | 操作表示を抑えて画像に集中。画面下部へマウスを移すとツールバーが現れ、「UI表示」で戻せる |
| 再読み込み       | 外部で追加・削除・置き換えたファイルや、変更した設定を反映                               |

「元サイズ」は一覧で画像の縦横比を保つ表示です。画像をクリックすると元画像を閲覧できます。

### 全画像一覧

「全画像一覧」を押し、確認ダイアログで続行すると、現在のフォルダーとその下のサブフォルダーにある画像をまとめて表示します。「戻る」で通常の一覧に戻ります。

### お気に入り

カードの「お気に入り」ボタンで、画像・動画・フォルダーを登録・解除できます。ツールバーの「お気に入り: 優先」で先頭にまとめ、「お気に入り: のみ」で登録したものだけに絞り込めます。「お気に入り: 無効」は通常の表示に戻す操作で、登録内容は残ります。

「お気に入り一覧」では、選択したルートフォルダー全体から、お気に入りの画像・動画をまとめて表示します。ホーム画面のお気に入りフォルダーとは別に管理します。

### 非表示と復元

ルート配下のサブフォルダーにあるアイテムは、カードの「非表示」ボタンで通常の一覧から除外できます。ファイル自体は削除しません。

対象のフォルダーで「非表示一覧」を開き、カードの「非表示を解除」を押すと復元できます。「戻る」で通常の一覧に戻ります。

## 画像・動画を閲覧する

画像ビューワーでは、見開き表示と単一表示を切り替えられます。ページは右から左へ読み進める順序です。見開きの組み合わせがずれている場合は「見開き調整」で1ページ分ずらせます。

「全画面」で表示を広げられます。全画面ではマウスを止めると操作ツールバーが隠れ、動かすと再表示されます。「閉じる」または Esc で一覧に戻ります。

動画はプレーヤーのコントロールで再生・一時停止・シークできます。Esc で一覧に戻ります。

### キーボードとマウス

| 操作                         | 動作                                                                     |
| ---------------------------- | ------------------------------------------------------------------------ |
| ←                            | 画像の次のページへ。見開き表示では次の見開きへ                           |
| →                            | 画像の前のページへ。見開き表示では前の見開きへ                           |
| Esc                          | 画像・動画の閲覧を閉じる                                                 |
| Alt + ← ／マウスの戻るボタン | 閲覧を閉じる、親フォルダーへ戻る。デスクトップ版のルートではホームへ戻る |
| Alt + → ／マウスの進むボタン | 戻る操作の直前のフォルダーや閲覧ページを復元                             |

別のフォルダーや画像・動画を開くと、進む履歴は消えます。

### パスをコピー

一覧の「パスをコピー」は現在のフォルダー、画像ビューワーの「パスをコピー」は閲覧中の画像のパスをコピーします。デスクトップ版ではフルパス、Web 版では選択したルートフォルダー名を起点とするパスになります。

## 設定の保存

お気に入り・非表示・フォルダーごとの表示設定は、選択したルートフォルダー内の `.image-viewer.json` に保存します。このファイルへの書き込み権限が必要です。

サムネイルサイズ、単一表示・見開き表示、UIの表示状態も次回起動時に引き継ぎます。フォルダーを開いたときは、そのフォルダーに保存された表示設定が適用されます。

ファイルや設定を別のアプリで変更した場合は、「再読み込み」で反映してください。

## 対応ファイル

- 画像: JPEG、PNG、GIF、WebP、BMP など
- 動画: MP4、WebM、MOV、OGG

表示・再生できる形式は、実行環境が対応する画像形式・動画コーデックにも依存します。

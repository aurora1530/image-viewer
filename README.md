# ローカル画像ビューワー

端末内のフォルダーから画像・動画・PDFを閲覧するアプリケーションです。サムネイル一覧から画像を開き、見開き表示でページを送れます。Windows のデスクトップ版と Web 版があります。

## 起動方法

### デスクトップ版

Windows 版の実行ファイルを起動します。ホーム画面には最近使ったフォルダーが表示され、次回から選び直さずに開けます。よく使うフォルダーは ★ でお気に入りに登録できます。オフラインでも利用できます。

### ソースから起動する場合

Node.js と npm が必要です。リポジトリのフォルダーで依存関係をインストールします。

```powershell
npm ci
```

デスクトップ版を起動する場合:

```powershell
npm run desktop:dev
```

Web 版を起動する場合:

```powershell
npm run dev
```

Web 版は表示された URL をブラウザーで開きます。フォルダー選択に対応した Chrome・Edge などの Chromium 系ブラウザーを使用してください。

## 基本の使い方

1. 「ルートフォルダを選択」、またはホーム画面の「新しいフォルダーを開く」で、閲覧するフォルダーを選びます。
2. 一覧の画像をクリックすると画像ビューワーが開き、動画をクリックすると再生が始まります。PDFをクリックすると、そのPDFの中身を閲覧できます。
3. フォルダーのサムネイルや名前をクリックすると、そのフォルダーの一覧へ移動します。カードの「開く」ボタンでは、フォルダー内の画像を直接閲覧できます。
4. 「上の階層へ」で親フォルダーに戻ります。デスクトップ版では「ホーム」から最近使ったフォルダーを選び直せます。

フォルダーを開くと一覧の先頭を表示します。「上の階層へ」で戻ると、開いていたフォルダーが見える位置を表示します。

## 一覧を探しやすくする

画面下部のツールバーは「フィルター」「並び替え」「表示」に分かれており、上部のフォルダー操作バーでは一覧モードの切り替えや再読み込みを行えます。

| 分類       | 操作             | 内容                                                                                     |
| ---------- | ---------------- | ---------------------------------------------------------------------------------------- |
| フィルター | 検索             | フォルダー名・ファイル名の一部で検索。大文字・小文字は区別しない                         |
| フィルター | 種別             | すべて・ディレクトリ・画像・GIF・動画・PDFで絞り込み                                     |
| フィルター | お気に入りのみ   | お気に入り登録したアイテムだけに絞り込み（再クリックで解除、登録内容は保持）             |
| 並び替え   | 名前の昇順・降順 | 数字を含む名前を考慮して並べ替え                                                         |
| 並び替え   | お気に入り優先   | お気に入り登録したアイテムを先頭にまとめて表示                                           |
| 表示       | サムネイルサイズ | 「小・中・大」と、画像の縦横比を保つ「元サイズ 小・中・大」の6種類から選択               |
| 表示       | UI非表示         | 操作表示を抑えて画像に集中。画面下部へマウスを移すとツールバーが現れ、「UI表示」で戻せる |
| 上部バー   | 一覧モード       | 「通常」「全画像一覧」「お気に入り一覧」「非表示一覧」を切り替え                         |
| 上部バー   | 再読み込み       | 外部で追加・削除・置き換えたファイルや、変更した設定を反映                               |

「元サイズ」は一覧で画像の縦横比を保つ表示です。画像をクリックすると元画像を閲覧できます。

### 全画像一覧

上部の一覧モードで「全画像一覧」を押し、確認ダイアログで続行すると、現在のフォルダーとその下のサブフォルダーにある画像をまとめて表示します。「通常」（または再度「全画像一覧」）を押すと通常の一覧に戻ります。

### お気に入り

カードの「お気に入り」ボタンで、画像・動画・PDF・フォルダーを登録・解除できます。下部ツールバーの「お気に入りのみ」で登録したものだけに絞り込み、「お気に入り優先」で先頭にまとめられます。解除しても登録内容は残ります。

上部の「お気に入り一覧」では、選択したルートフォルダー全体から、お気に入りの画像・動画・PDFをまとめて表示します。ホーム画面のお気に入りフォルダーとは別に管理します。

### 非表示と復元

ルート配下のサブフォルダーにあるアイテムは、カードの「非表示」ボタンで通常の一覧から除外できます。ファイル自体は削除しません。

対象のフォルダーで上部の「非表示一覧」を開き、カードの「非表示を解除」を押すと復元できます。「通常」（または再度「非表示一覧」）で通常の一覧に戻ります。

## 画像・動画・PDFを閲覧する

画像ビューワーでは、見開き表示と単一表示を切り替えられます。ページは右から左へ読み進める順序です。見開きの組み合わせがずれている場合は「見開き調整」で1ページ分ずらせます。

「全画面」で表示を広げられます。全画面ではマウスを止めると操作ツールバーが隠れ、動かすと再表示されます。「閉じる」、Esc、または画像・PDFの周囲の余白をクリックすると一覧に戻ります。

PDFは先頭ページのサムネイルをクリックして開きます。開いたPDFのページを単一表示・見開き表示で閲覧でき、矢印キーによるページ送りと「見開き調整」も使えます。ページ送りはそのPDF内で循環し、別のPDFや画像には移動しません。PDF.jsと描画に必要なリソースを同梱しているため、オフラインでも利用できます。パスワード付きPDFには対応していません。「全画像一覧」は画像のみを対象とし、PDFは通常の一覧・お気に入り一覧から開きます。

動画はプレーヤーのコントロールで再生・一時停止・シークできます。Esc、またはプレーヤーの周囲の余白をクリックすると一覧に戻ります。

### キーボードとマウス

| 操作                         | 動作                                                                     |
| ---------------------------- | ------------------------------------------------------------------------ |
| ←                            | 画像・PDFの次のページへ。見開き表示では次の見開きへ                      |
| →                            | 画像・PDFの前のページへ。見開き表示では前の見開きへ                      |
| Esc                          | 画像・動画・PDFの閲覧を閉じる                                            |
| Alt + ← ／マウスの戻るボタン | 閲覧を閉じる、親フォルダーへ戻る。デスクトップ版のルートではホームへ戻る |
| Alt + → ／マウスの進むボタン | 戻る操作の直前のフォルダーや閲覧ページを復元                             |

別のフォルダーや画像・動画を開くと、進む履歴は消えます。

### パスをコピー

一覧の「パスをコピー」は現在のフォルダー、画像ビューワーの「パスをコピー」は閲覧中の画像またはPDFファイルのパスをコピーします。デスクトップ版ではフルパス、Web 版では選択したルートフォルダー名を起点とするパスになります。

デスクトップ版では、隣の「フォルダーを外部で開く」で現在のフォルダーをエクスプローラーやFinderなど、OS標準のファイル管理アプリで開けます。サブフォルダーに移動した場合はそのフォルダーが対象です。Web版にはこのボタンは表示しません。

## アプリ全体の設定

画面上部の「設定」でキャッシュの容量上限と現在の使用量を確認できます。サムネイル用メモリと元画像用メモリはそれぞれ既定で512 MiB、デスクトップ版のサムネイル用ディスクは3072 MiBです。容量を下げると古いキャッシュを解放し、0にすると保持しません。通常の保存時はまとめて整理するため、ディスク上限は一時的に超える場合があります。ファイル数による上限はありません。

使用量は2秒ごとに更新する保持中の画像データのサイズです。表示・デコード中の画像、ディレクトリ情報などを含むアプリ全体のメモリ使用量ではありません。Web版は画像キャッシュをメモリだけに保持します。

容量設定は「容量設定を保存」で保存します。Web版は利用中のサイトのlocalStorage（`image-viewer-config`）、デスクトップ版はElectronの`userData`内の`settings.json`へ保存し、次回起動時に適用します。デスクトップ版のサムネイルは同じ場所の`thumbnails`に保存します。実際の保存先は設定画面に表示します。

同じ画面からサムネイルサイズと単一ページ表示も変更できます。これらの表示設定は変更時に保存されます。

## 設定の保存

お気に入り・非表示・フォルダーごとの表示設定は、選択したルートフォルダー内の `.image-viewer.json` に保存します。このファイルへの書き込み権限が必要です。

サムネイルサイズ、単一表示・見開き表示、UIの表示状態も次回起動時に引き継ぎます。フォルダーを開いたときは、そのフォルダーに保存された表示設定が適用されます。

ファイルや設定を別のアプリで変更した場合は、「再読み込み」で反映してください。デスクトップ版もファイル一覧を永続キャッシュせず、再読み込み時はフォルダーの更新日時にかかわらず実ファイルを読み直します。

フォルダーの代表サムネイルは、直下の `__0`・`icon`・`thumbnail` という名前の画像をこの順で優先します。各名前について `.jpg`・`.jpeg`・`.png`・`.gif`・`.webp`・`.bmp`・`.heic` の順で候補パスを直接確認します。優先画像の確認のためにフォルダー全体を列挙することはありません。大小文字の扱いはファイルシステムに従い、通常のWindows環境では `ICON.PNG` なども見つかります。大小文字を区別する環境では小文字の候補名に合わせてください。

優先画像がなければ、有効な保存済みパスから画像・PDFを直接取得します。保存済みパスもない・期限切れ・取得不能の場合だけ、直下のメディア、最初のサブフォルダーの順に探索します。代表画像の選択は一覧表示の結果に依存せず、後から追加した優先画像も次回の取得時に選びます（表示中のカードの自動更新は行いません）。選んだ優先画像は保存済みパスにも反映します。探索結果のパスと1週間の有効期限は、ルートの `.image-viewer.json` 内の各フォルダーの `directoryThumbnail` に保存します。画像データは保存せず、保存済みパスを利用するだけでは期限を延長しません。設定を書き込めない場合もサムネイルは表示できます。

## 対応ファイル

- 画像: JPEG、PNG、GIF、WebP、BMP など
- 動画: MP4、WebM、MOV、OGG
- 文書: PDF（先頭ページのサムネイルと全ページの閲覧）

表示・再生できる形式は、実行環境が対応する画像形式・動画コーデックにも依存します。

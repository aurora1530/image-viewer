# ローカル画像ビューワー

端末内の画像・動画・PDFを閲覧するElectron / Webアプリです。サムネイル一覧、見開き表示、お気に入りに対応し、デスクトップ版はオフラインでも使えます。

## 起動

デスクトップ版は配布された実行ファイルを起動します。ソースからの起動にはNode.js 24とnpmが必要です。

```powershell
npm ci
npm run desktop:dev  # Electron版
npm run dev          # Web版
```

Web版は表示されたURLをChrome・Edgeなど、フォルダー選択に対応したChromium系ブラウザーで開いてください。

## 基本操作

1. 「ルートフォルダを選択」または「新しいフォルダーを開く」で閲覧先を選ぶ。
2. フォルダーの名前・サムネイルで一覧へ移動し、「開く」でフォルダー内の画像を直接閲覧する。
3. 画像・動画・PDFをクリックして開き、「閉じる」・Esc・周囲の余白クリックで一覧に戻る。
4. 「上の階層へ」で親へ戻る。開いていたフォルダーが見える位置に戻る。

デスクトップ版のホームには履歴とお気に入りフォルダーを表示します。★で登録し、「⠿」のドラッグかフォーカス後の矢印キーで並び替えられます。順序は保存され、新規登録は末尾に追加されます。お気に入り解除・履歴削除には確認画面が出ます。

## 一覧

| 場所             | 操作                                                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------------------- |
| 下部のフィルター | 名前の部分一致検索（大小文字を区別しない）、種別、お気に入りのみ                                     |
| 下部の並び替え   | 数字を考慮した名前の昇順・降順、お気に入り優先                                                       |
| 下部の表示       | サムネイルの小・中・大、縦横比を保つ元サイズの小・中・大。「隙間を詰める」で余白のない配置へ切り替え |
| 上部の一覧モード | 通常・全メディア一覧・お気に入り一覧・非表示一覧                                                     |
| 上部の再読み込み | 外部で変更したファイル・設定を反映                                                                   |

「UI非表示」で操作表示を隠せます。画面下部へマウスを移し、「UI表示」で戻します。

- **全メディア一覧**: 確認後、現在のフォルダー以下の画像・動画・PDFをまとめて表示します。種別「ディレクトリ」は選択できません。
- **お気に入り**: カードで画像・動画・PDF・フォルダーを登録できます。「お気に入りのみ」は現在の一覧を絞り、「お気に入り一覧」はルート全体の登録ファイルを表示します。ホームのお気に入りとは別管理です。
- **非表示**: ルート配下のサブフォルダー内のアイテムを通常一覧から除外します。ファイルは削除せず、そのフォルダーの「非表示一覧」で解除できます。

各一覧モードは「通常」、または同じモードを再度押すと解除できます。

## 閲覧とショートカット

画像・PDFは単一表示と見開き表示を切り替えられます。右から左へ読み進め、「見開き調整」で組み合わせを1ページずらせます。「全画面」ではマウスを止めるとツールバーが隠れます。動画はプレーヤーで再生・一時停止・シークできます。

PDFのページ送りは同じPDF内で循環します。オフラインで閲覧できますが、パスワード付きPDFには対応していません。

| 操作                   | 動作                                                       |
| ---------------------- | ---------------------------------------------------------- |
| ← / →                  | 画像・PDFの次 / 前のページ（見開きでは見開き単位）         |
| Esc                    | 閲覧を閉じる                                               |
| Alt + ← / マウスの戻る | 閲覧を閉じる・親へ戻る。デスクトップ版のルートではホームへ |
| Alt + → / マウスの進む | 戻る前のフォルダー・閲覧位置を復元                         |

別のフォルダーやファイルを開くと、進む履歴は消えます。

「パスをコピー」は一覧では現在のフォルダー、ビューワーでは画像・PDFが対象です。デスクトップ版はフルパス、Web版はルート名からのパスをコピーします。デスクトップ版の「フォルダーを外部で開く」はOS標準のファイル管理アプリを開きます。

## 設定と保存先

上部の「設定」でキャッシュ容量・代表画像の優先名・表示設定を変更できます。容量と優先名は「設定を保存」、表示設定は変更時に保存します。

| 設定・データ                                           | 保存先                                                                         |
| ------------------------------------------------------ | ------------------------------------------------------------------------------ |
| お気に入り・非表示・フォルダー別表示設定・代表画像パス | ルート内の`.image-viewer.json`（書き込み権限が必要）                           |
| Web版の共通設定                                        | localStorageの`image-viewer-config`                                            |
| デスクトップ版の共通設定 / サムネイル                  | Electronの`userData`内の`settings.json` / `thumbnails`（設定画面に実パス表示） |

表示設定は次回起動時に引き継ぎ、フォルダーを開くとそのフォルダーの設定を適用します。外部で変更したファイル・設定は「再読み込み」で反映してください。

### キャッシュ

既定の上限はサムネイル・元画像のメモリが各512 MiB、デスクトップ版のディスクが3072 MiBです。0で保持を無効にします。ディスクはまとめて整理するため、一時的に上限を超える場合があります。表示する使用量は保持中の画像データのみで、アプリ全体のメモリ使用量ではありません。Web版はメモリのみです。

「永続キャッシュを削除」でディスク上のサムネイルを消せます。元画像・設定・お気に入り・履歴は保持し、必要なサムネイルを再生成します。

### フォルダーの代表画像

優先する画像名を拡張子なしで1行ずつ指定します。既定は`__0` → `icon` → `thumbnail`です。空欄で保存すると優先名を使いません。表示中のカードへは「再読み込み」で反映します。

優先名の画像がなければ保存済みパスを使い、それも使えなければ直下のメディア・最初のサブフォルダーの順に探します。パスの有効期限は1週間で、画像データはルート設定に保存しません。大小文字を区別する環境では候補名を小文字にしてください。

## 更新

ヘッダーのバージョンからその版のReleaseを開けます。設定の「バージョンと更新」で最新版を確認できます。

- Web版: 起動時・10分ごとに確認し、「再読み込みして更新」で適用。
- Windowsインストール版: 起動時・4時間ごと・手動で確認。ダウンロード後、「再起動して更新」で設定保存後に適用。保存失敗時はアプリを開いたままにする。
- Windows Portable・展開版・開発起動、macOS版: 最新リリースを手動でダウンロードして置き換え。

## 対応形式

画像はJPEG・PNG・GIF・WebP・BMPなど、動画はMP4・WebM・MOV・OGG、文書はPDFに対応します。表示・再生の可否は実行環境の画像形式・動画コーデックにも依存します。
